# Luhn Mod-36 网页工具

ID 格式: `AAAxxxxxxxxxxxxc-yyy`

- AAA: 国家代码 3 位大写字母 (不参与校验序列)
- BBBBBBBBBBBB: 12 位主体（小写字母或数字）参与 Luhn
- C: 校验位（根据主体 12 位 + 末尾 3 位计算）
- DDD: 3 位小写字母或数字（参与 Luhn）

计算校验位所用序列 = 主体 12 位 + 末尾 3 位，共 15 位。

## Luhn Mod-36 算法说明

类似 Luhn10，但字符集扩展到 0-9A-Z (36 个)，采用模 36。

1. 映射: `0-9 -> 0-9`, `A-Z -> 10-35`。
2. 从左到右遍历 (不含校验位和连接号-)：奇数位置 *2，，若结果 >=36 则减 35（相当于十进制 Luhn 的“拆位求和”扩展方式）。
3. 累加得到 S，校验值 = `(36 - (S mod 36)) mod 36`，再映射回字符。

## 使用

直接在浏览器打开 `index.html`。

- “校验现有 ID” 输入完整 ID，点击“校验”按钮得到结果（会自动规范大小写：前三位转大写，主体与尾段转小写，校验位转大写）。
- “生成新的 ID” 可选填国家代码或主体部分（不合法或缺失则自动随机），点击“生成”获得合法 ID。
